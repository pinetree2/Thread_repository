02Problem

02

검증

커뮤니티 반응과 실제 발표·사실은 분리해야 합니다.

03

게시 위험

자동 생성 글을 무검토 게시하면 사실성과 평판 위험이 생깁니다.

03Solution

하나의 생성이 아니라,
역할의 연쇄.

Detect

서로 다른 실시간 Source의 관심 신호를 정량화합니다.

Verify

공식 자료·뉴스로 다시 조사하고 신뢰도를 계산합니다.

Create safely

검증 사실만으로 작성·심사하고 사람 승인 뒤 게시합니다.
